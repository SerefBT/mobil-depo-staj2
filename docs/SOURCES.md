# Resmi teknik kaynaklar

Projedeki SDK ve bağımlılık sürümleri geliştirme sırasında resmi dağıtım metadata'ları üzerinden doğrulandı. Tekrar üretim için toolchain.json, pubspec.lock ve NuGet packages.lock.json dosyalarını kullanın.

- [.NET indirme ve destek](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- [EF Core transaction](https://learn.microsoft.com/en-us/ef/core/saving/transactions)
- [ASP.NET Core Identity](https://learn.microsoft.com/en-us/aspnet/core/security/authentication/identity)
- [Flutter SDK arşivi](https://docs.flutter.dev/install/archive)
- [Flutter Android dağıtımı](https://docs.flutter.dev/deployment/android)
- [PostgreSQL Windows dağıtımı](https://www.postgresql.org/download/windows/)
- [PostgreSQL satır kilitleri](https://www.postgresql.org/docs/current/explicit-locking.html)
- [Android ağ güvenlik yapılandırması](https://developer.android.com/privacy-and-security/security-config)
- [mobile_scanner](https://pub.dev/packages/mobile_scanner)
- [flutter_secure_storage](https://pub.dev/packages/flutter_secure_storage)
- [flutter_local_notifications](https://pub.dev/packages/flutter_local_notifications)
